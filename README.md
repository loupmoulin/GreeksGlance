GreeksGlance is a web application to visualize financial option Greeks (BlackScholes model).

Dynamic curve display: Delta, Gamma, Vega, Theta.
Two display modes: single chart or dual comparison.

To launch the project, you must first have Streamlit installed. If that is not the case, open your terminal and type these two commands:

pip install streamlit numpy scipy plotly

streamlit run GG.py
